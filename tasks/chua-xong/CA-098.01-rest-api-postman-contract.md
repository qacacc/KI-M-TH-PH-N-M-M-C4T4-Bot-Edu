## Mục tiêu

Mô tả Workspace/Collection/Environment và cách nhóm gọi REST API HTTP thực của project bằng Postman. Chuẩn hóa contract cho Profile, Schedule, Exams mà không thay thế connector UTH chưa xác minh bằng dữ liệu mẫu.

## Truth check

- CONFIRMED trước task: Axum API đã bind loopback và có các route local; JSON envelope và các lỗi hiện hành nằm trong `src-tauri/src/api.rs`.
- CONFIRMED trước task: `ensure_uth_contract_verified()` luôn trả `CONTRACT_UNVERIFIED`; không đọc cache/lấy data UTH qua Schedule/Exams.
- UNKNOWN: method/auth/schema thật của API portal UTH; ngoài phạm vi và không nâng trạng thái thành VERIFIED.
- TARGET: REST local yêu cầu Bearer token từ `CAMPUS_ASSISTANT_LOCAL_API_TOKEN`; Postman gọi HTTP với token ở local secret value.

## Phạm vi

- Bổ sung Bearer middleware cho tất cả route REST loopback; token thiếu/sai trả 401, cấu hình token sai thì REST server không mở port còn app desktop chạy.
- Map connector gate sang 503; lỗi đọc cache nội bộ sang 500 generic; giữ các lỗi validation/not-connected rõ ràng.
- Cập nhật Postman collection/environment, tài liệu `docs/testing/REST_API_DESIGN.md` và các docs/tracking cần thiết.
- Không mở khóa UTH, không thêm response fixture giả, không gửi request tới portal.
