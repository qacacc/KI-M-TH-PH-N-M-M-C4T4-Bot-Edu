# MVP 0.1

## Muc tieu

Tao mot ung dung desktop local co mot luong chay that:

```text
tim tai lieu lap trinh mang
→ chuan hoa cau
→ nhan dien FIND_DOCUMENTS
→ trich xuat mon Lap trinh mang
→ hoi hoc ky neu thieu
→ nhap hoc ky 1
→ doc JSON local
→ hien thi danh sach tai lieu
→ chon file
→ yeu cau xac nhan
→ mo file hoac copy sang downloads
→ ghi action log metadata
```
